# Portfolio Assignment 2
Solution for the second portfolio assignment about danish monarchs

### Data
The data used in this assignment: `konger.csv` was made with a combination of information from `Lex` and `Kongehuset`
- Kongehuset. “Kongerækken” https://www.kongehuset.dk/monarkiet-i-danmark/kongerakken
- Poulsen, Bjørn. “Kongerækken i Danmark” *Lex.dk*. https://lex.dk/konger%C3%A6kken_i_Danmark
